## Course Description
This course introduces the foundations of supervised, unsupervised, and reinforcement learning. We cover linear models, decision trees, neural networks, model selection, and modern transformer architectures at a working-knowledge depth. By the end of the course students should be able to frame a real-world problem as a learning task, choose an appropriate model family, train and evaluate it, and diagnose its failure modes.

## Academic Integrity
You may discuss assignments at the conceptual level with classmates. **No code sharing.** All submissions are run through MOSS. First offense: zero on assignment. Second: report to the dean. Generative-AI tools (ChatGPT, Copilot) are **allowed for code completion and debugging only** — you must include a brief acknowledgement at the top of every submission stating which tools you used and how. Submitting model-generated text as your own writing is a violation.
